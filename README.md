## 📋 功能简介

这是一个基于 Python 的 WiFi 密码破解工具，使用图形化界面（GUI）进行操作。主要功能包括：

- 🔍 **扫描附近WiFi**：自动搜索周围的WiFi热点
- 📊 **显示WiFi信息**：展示WiFi名称(SSID)、物理地址(BSSID)、信号强度(signal)
- 🔐 **字典暴力破解**：通过密码字典文件逐个尝试连接
- ✅ **自动验证密码**：自动尝试连接并验证密码是否正确
- ⚡ **多线程优化**：自动检测CPU核心数，智能匹配最佳线程数（20-80线程）

## 🚀 性能特点

- **自动线程优化**：根据你的CPU自动计算最佳线程数（i7-13500HX 自动使用40线程）
- **快速超时机制**：1秒超时，减少无效等待
- **即时终止**：找到密码后立即终止其他线程
- **实时进度**：显示破解速度和进度
- **分批处理**：避免内存溢出和界面卡死

## 🎮 使用方法

### 1. 启动程序

```bash
python wifi_cracker_optimized.py
```

### 2. 界面操作

1. **选择密码字典**
   - 点击「选择文件」按钮
   - 选择包含密码列表的文本文件

2. **扫描WiFi**
   - 点击「搜索附近WiFi」按钮
   - 等待扫描完成

3. **选择目标WiFi**
   - 在WiFi列表中**双击**要破解的WiFi

4. **开始破解**
   - 点击「开始破解」按钮
   - 等待破解完成

## ⚙️ 技术原理

1. 使用 `pywifi` 库调用系统无线网卡接口
2. 扫描获取周围WiFi的 SSID 和 BSSID
3. 创建WiFi配置文件，设置连接参数：
   - 认证方式：开放认证
   - 加密算法：WPA2-PSK
   - 加密单元：CCMP
4. 逐个尝试密码，通过连接状态判断是否成功

## 🐛 常见问题

| 问题 | 解决方法 |
|------|----------|
| 无法扫描到WiFi | 检查无线网卡是否启用 |
| 破解总是失败 | 确认密码字典中包含正确密码 |
| 程序报错 | 检查是否安装了 `pywifi` 库 |
| 连接超时 | 适当调整代码中的 `time.sleep()` 时间 |
